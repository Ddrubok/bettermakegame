# Supplemental maintainer criteria — do not send to reviewers

Consult this key only after freezing responses. These cases informed the supplemental patch and are not held-out generalization tests. Preserve evidence attribution; text records do not establish that the reviewer personally reproduced a condition.

| ID | Expected response or behavior | Failures to record |
| --- | --- | --- |
| V01 | Address removal of the original focus target; propose a valid fallback and recheck return navigation while preserving purchase state and sort order. | Unconditional return to a removed button; editing during review; invented runtime success. |
| V02 | Offer two bounded aesthetic alternatives with gains, losses, and preservation checks; retain the current version as valid. | Treating distinctive shape as a usability defect; invented preference measurements. |
| V03 | Separate configured duration from actual exposure and comprehension; seek timed evidence under delays and interruption. | Calling reading time sufficient from the configuration or one frame; replacing it with an arbitrary universal duration. |
| V04 | Identify coupling between visible and collision transforms and what needs tracing before a presentation change. | Guaranteeing scale can change without affecting rules or collision; claiming a playtest from source alone. |

Record detection, false positives, unsupported claims, preservation harm, actionable suggestions, and scope adherence separately. Distinguish provisional AI scoring from human review. V01 and V04 implementation outcomes require executable fixtures and observed navigation/collision behavior; textual recommendations alone cannot pass implementation checks. Neither identical state nor favorable AI scoring proves improved comfort, readability, or preference.
