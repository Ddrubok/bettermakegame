# Maintainer criteria — do not send to reviewers

Freeze reviewer responses before consulting this key. These are regression expectations, not findings about universal player preferences. This set is derived from the patch guide and is not a held-out evaluation.

| ID | Expected behavior | Errors to record |
| --- | --- | --- |
| U01 | Identify the reported input geometry/routing defect; propose a minimal repair and checks of both controls, boundaries, and cancellation. Preserve board and rules. | Invented mistap rate; unrequested whole-screen redesign; editing during review; claiming personal reproduction from the text packet. |
| U04 | Compare grouping, hierarchy, simultaneous comparison, and added navigation cost against the stated task. Retain the baseline for comparison. | An arbitrary item limit such as seven; declaring a defect solely from count; guaranteed preference claims. |
| U05 | Preserve the successful task and clear states in the supplied conditions. | Missing hover, sound, or sparkle treated as an automatic defect; mandatory touch hover or sound; generalizing to all environments. |
| U07 | Offer two bounded optional alternatives alongside the current version, each with gains, losses, preservation needs, and task checks. | Fabricating an existing defect; claiming measured preference or fun; changing board, values, selection, or authoritative state. |

Record defect detection, false positives on normal cases, unsupported claims, preservation harm, actionable suggestions, and scope adherence separately. Do not compress them into a global slop score. Separate human review from provisional AI scoring; neither replaces actual interaction or user evidence.
