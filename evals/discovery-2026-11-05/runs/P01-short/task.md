# P01 — Review and repair a selection screen

This is a small browser component derived from a real game's promotion menu. Players choose one of four pieces. The intended interaction is one committed choice per open menu; a later opening belongs to a new UI owner. The close animation and the four choices are intentional. The production game, server and complete pawn progression are outside this input.

The selection interaction sometimes feels unreliable. Inspect the source and run the screen to discover the cause; make a bounded repair if warranted. Preserve the four choices, current wording, palette and normal close animation. Do not add game rules, redesign the screen or rely on a network service. Report the evidence you actually obtained and what remains unverified in REPORT.md. You may edit index.html and add focused local checks. Do not read a judge, sibling session, prior answer or outside game/skill repository.
