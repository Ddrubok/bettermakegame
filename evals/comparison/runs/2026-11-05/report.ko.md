# 짧은 프롬프트와 전체 스킬 비교 — 2026-11-05

[English](report.md) | [한국어](report.ko.md)

짧은 프롬프트와 전체 스킬 모두 사전 검사에서 세 사례를 해결했습니다. **이번처럼 요구사항이 명확한 작은 수정에서는 전체 스킬의 추가 정확도 이점이 확인되지 않았습니다.** 다른 작업과 모델에서도 동등하다는 결론은 아닙니다.

| 사례 | 짧은 지침 | 전체 스킬 | 관찰 결과 |
| --- | --- | --- | --- |
| R01: 아날로그 입력 해제 | 5/5 | 5/5 | 양쪽 모두 해제 후 잔류 입력을 처리하고 활성 아날로그 입력과 반스로틀 동작을 보존 |
| E01: 종료된 효과 | 4/4 | 4/4 | 양쪽 모두 라운드별 종료 이력과 활성 효과의 보정을 유지 |
| J01: 점프 경계·모달 | 5/5 | 5/5 | 양쪽 모두 같은 두 기능 문제를 수정 |

조건별 14개 검사는 세 사례에 속한 서로 관련된 요구사항이며 독립적인 게임 실험 14회가 아닙니다. 여섯 결과물의 문법 검사와 각 에이전트가 만든 검사를 관리 에이전트가 다시 실행해 통과했습니다. 과제·제공 스킬 파일의 보존과 반환 파일 범위를 확인했으며, 코드 변경에서 요청하지 않은 게임 기능 추가는 발견하지 못했습니다.

## 방법과 근거

- 호스트의 기본 에이전트 도구로 `gpt-6-astra`를 요청한 새 문맥 6개를 사용했고 이전 대화는 전달하지 않았습니다. 같은 호스트와 Node v22.18.0을 사용했으며 추론 강도는 별도로 지정하지 않았습니다. 정확한 서비스 모델 버전과 완전한 접근 기록은 독립적으로 확인할 수 없었습니다.
- 사례·조건당 1회씩 실행했습니다. R01 짧은 지침/전체 스킬과 E01 짧은 지침을 먼저, E01 전체 스킬과 J01 두 조건을 다음에 실행했습니다. 병렬 실행이 가능했으므로 실행 시간은 통제된 비교가 아니며 속도 우위를 주장하지 않습니다.
- 두 조건에 동일한 과제와 시작 코드를 제공했습니다. 짧은 조건에는 원칙 한 문단을, 전체 조건에는 고정한 실행용 스킬 패키지와 관련 참고 문서를 읽으라는 지시를 제공했습니다. 준비한 폴더에서 판정 파일·완성 해답·다른 응답을 제외했습니다.
- 파일 분리와 접근 지시를 사용했으며 OS 샌드박스는 아니었습니다. 반환된 파일을 확인했지만 모든 파일 읽기를 감사하지는 않았습니다. 완전한 블라인드·격리 연구가 아닙니다. 과제와 판정기를 만든 관리 에이전트는 내용을 알고 있었고, 사례도 익숙한 공개 예제에서 왔습니다.

[결과](results.json), [준비한 입력 해시](prepared-inputs.json), [outputs 폴더](outputs)의 결과물·한국어 원본 보고서·검사 코드를 참고하세요. 보고서에서는 기기별 Node 실행 파일 경로만 정규화했으며 구현과 검사 스크립트의 원본 바이트는 보존했습니다.

## 사후 추가 확인

사전 채점 뒤 같은 [추가 검사](posthoc-probe.mjs)로 두 E01 결과물에 `dispose()`와 `finish('late-cleanup')`를 순서대로 호출했습니다. 어느 쪽도 활성 효과를 되살리지 않았습니다. 짧은 지침 결과물은 새로 추가한 종료 ID 집합을 비워 둔 반면, 전체 스킬 결과물은 정리 후 ID 하나를 다시 기록했습니다. 관리자가 수정한 기준 예제도 종료 이력을 남기지 않았습니다.

이는 해당 전체 스킬 결과물의 정리 경로 검토 사항입니다. 사전 판정 항목 밖이므로 **기존 4/4 점수를 사후 변경하지 않았습니다.** 기록된 결과물에 후속 에이전트 수정을 적용하지도 않았습니다. 스킬 사용이 일반적으로 결과를 악화시킨다는 증거는 아닙니다.

## 남은 한계

기존 U/V 비교는 별도 사례이므로 NOT RUN(미실행)을 유지합니다. 사람의 체감·선호와 플레이테스트, 한국어 자동 호출, 실기기·실네트워크, Unity·Godot·Unreal 실행은 미검증입니다. 후속 평가는 더 어렵거나 요구가 덜 명시적인 새로운 사례에서 조건별로 반복하고, 과제 범위와 사람의 검토를 유지해야 합니다. 이번 정답을 지침에 넣거나 유리한 점수를 만들기 위해 스킬을 확장해서는 안 됩니다.
