# 수정 및 검증 결과

`finish(id)`가 활성 효과만 삭제하고 시각 수명의 종료를 기록하지 않아 높은 리비전 수신 시 효과가 재생성되는 원인을 확인했습니다.

`impact.mjs`에 라운드별 종료 ID 집합을 추가했습니다. 종료 이후에도 정상적인 리비전 및 확정 이력은 갱신하되 효과 생성과 성공 버스트는 차단합니다. 확정 전 종료, 아직 수신되지 않은 ID의 종료도 유지됩니다. 새 라운드와 dispose에서는 종료 기록을 지우고, dispose 이후 finish는 기록을 추가하지 않습니다. 시뮬레이션과 시간 처리에는 손대지 않았습니다.

실제로 실행한 명령:

- `node check.mjs`: 수정 전 종료된 확정 효과의 재등장 assertion 실패로 재현했습니다. 수정 후 전체 통과했습니다.
- `node --check impact.mjs`: 통과했습니다.

`check.mjs`에서 종료된 확정/미확정 이벤트의 재수신 및 버스트 억제, 반복 finish, 수신 전 finish, 중복/역순 리비전, 확정 후 pending 차단, 살아 있는 효과의 위치 보정, 거절 처리, 같은 라운드의 다른 이벤트, 새 라운드의 ID 재사용, 잘못된 메시지, 다른 라운드 무시, dispose 및 합성 시뮬레이션 결과 일치를 검증했습니다.

한계: 실제 네트워크나 렌더러가 없는 fixture이므로 화면 표현, 실제 통신 지연, 실게임 통합은 검증하지 않았습니다. 의존성 설치나 외부 접근 없이 제공된 로컬 모델만 검증했습니다.
